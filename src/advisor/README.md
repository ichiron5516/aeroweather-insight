# 揺れ回避 経路アドバイス（AeroWeather Insight 追加機能）

画面左上の「✈ 経路アドバイス」から使います。出発・到着を選んで「評価する」を押すと、次の処理をします。

1. その区間の登録経路（AIC標準経路、悪天・混雑回避登録経路、経路エディタで保存した自作経路）を集める。
2. 最新の気象データで、経路ごと・巡航高度ごとに揺れのリスクを採点する。
3. 揺れの少ない Route と高度を推奨し、3D に描く。

## 見るもの（リアルタイム）

| 要因 | データ | 判定 |
|---|---|---|
| 晴天乱気流（CAT） | Open-Meteo 経由の気象庁 MSM/GSM。500/400/300/250/200hPa の風とジオポテンシャル高度を約1°格子で取得 | Ellrod 指数 TI = 鉛直シア × 水平変形（×1e-7）。4以上=弱、8以上=並、12以上=強 |
| 対流雲・雷雨 | 気象庁 高解像度降水ナウキャスト（最新の実況タイル） | 経路の左右10NMの最大降水強度。10mm/h以上=弱、20以上=並、50以上=強 |
| SIGMET | NOAA Aviation Weather Center の国際SIGMET（福岡FIR周辺） | 通過時刻・高度・範囲が重なる TS/TURB/MTW。SEV または TS は強、それ以外は並 |
| 衛星画像・天気図 | 気象庁 ひまわり赤外、地上天気図、国内悪天予想図（FBJP） | 表示のみ（採点には使わない） |

## 採点のしかた

- 経路を5NMごとに区切り、上昇250ft/NM・降下320ft/NMの高度プロファイルと、通過時刻を見積もる。
- 揺れ評価 = 区間ごとの「強さの重み（弱1・並4・強12）× 通過時間（分）」の合計。CATは各時刻の予報格子を使う。
- 巡航高度は、進行方向に合う高度（東行き奇数FL・西行き偶数FL、FL410まで）をすべて試し、揺れ評価が最小の高度を推奨する。
- 順位は「揺れ評価 + 最短経路より長い距離 × 0.12」で決める。
- 登録経路の条件も読む：FL制限（FL250+ など）、時間帯（EOBT/ETA）、機種（for DH8D など）、条件付き（AIP SUP・停波・〜に限る）。条件に合わない経路は「対象外」として一覧の下に表示し、推奨には使わない。

## 組み込み手順

1. `src/advisor/` フォルダをそのまま `src/` に置く。
2. `public/data/nav/` に `airport_db.json`・`nav_db.json`・`route_db.json` を置く。
3. `src/main.js` に3か所追加する。

先頭の import の並び（`import 'cesium/Build/Cesium/Widgets/widgets.css';` の次の行）：

```js
import { initAdvisor } from './advisor/advisor.js';
```

`window.Cesium = Cesium;` の次の行：

```js
// ---- 揺れ回避 経路アドバイス（リアルタイム気象で登録経路を採点） ----
const advisorReady = initAdvisor(viewer);
```

高度誇張ボタン（`exagBtn`）の処理の中、`ALT_SCALE = ALT_SCALE === 1 ? 25 : 1;` の次の行：

```js
  advisorReady.then(a => a?.setAltScale(ALT_SCALE));
```

その後は、いつもどおりビルドして `dist` に Cesium のアセットをコピーし、デプロイします。

## 注意

- 教育用の簡易評価です。実運航の判断には使用できません。
- 山岳波は評価に含めていません。
- 衛星画像（雲頂温度）は表示だけで、採点には使っていません。
- レーダーは最新の実況1枚です。出発時刻を後にしても、対流雲の評価は今のエコーで行います。CAT は予報（最大12時間先）を使います。
- 取得できなかったデータがあっても、残りのデータで評価します。その場合、パネルの「気象データ」欄に「取得できません（〜は評価外）」と表示されます。
